# Kadenz＋ECHO-B：死亡金属 Riff 清晰与适度冲击 V5

2026-11-01 定制试听方案：[配置 JSON](../../../../presets/echo-b/moondrop/kadenz/kadenz-riff-impact-v5.json)。目标是跟住吉他 riff 的音高、节奏与编曲层次，同时保留适度低频力量。本次以已复核的官方数值为依据重新设计，没有修改设备或恢复工作区已删除的旧预设。

## 数据如何影响本次选择

两份官方文件经[本次来源复核](../measurements/provenance/official-data-recheck-20261101.json)确认与本地逐字节一致。每份 957 点，20–19896.974609 Hz；5128 与 4128 分别处理，不混合，不直接相减作为 EQ。

各曲线在 500 Hz 归零后，5128 / 4128 的 30 Hz 分别约 +7.20 / +6.40 dB，100 Hz 为 +3.54 / +4.67 dB。深低频并不缺失；200–500 Hz 没有共同的宽幅隆起。因此选择少量收深低频，把额外力量集中在约 100 Hz，并保留中低频主体。原始 SPL 归零后的数值不是偏离听感目标的误差，不能把这些正值全部削掉。[官方数据与说明](../measurements/README.md)

两套数据都有约 3 kHz 宽峰，但没有当前用户普遍刺耳的反馈，也未选定同测量系统的目标曲线，本版保留该轮廓。8 kHz 以上系统间差异明显，不补窄谷、不追求把高频拉平。官方产品有可更换导管与不同耳套，但这两份官方数据未注明使用条件，不能冒充用户当前配件的实测。[官方产品页](https://moondroplab.com/en/products/kadenz) · [现有条件核查](sources.md)

900 Hz 的小幅提升属于个人偏好试验：尝试让吉他主体和音符走向更容易跟随，并非测量证明该位置有缺陷，也不宣称 EQ 能分离已经混在同一频段的乐器或提升硬件解析力。

## 三段参数

| 类型 | 频率 | 单段增益 | Q / S | 设计意图 |
| --- | ---: | ---: | --- | --- |
| 低架 | 78 Hz | −1.2 dB | S=1，JSON q=1 | 温和收深低频，保留已有底座 |
| 峰值 | 100 Hz | +1.2 dB | Q=1 | 保留鼓点、贝斯的冲击与落点 |
| 峰值 | 900 Hz | +0.6 dB | Q=0.8 | 温和保留吉他中频主体与音高线条 |

沿用当前 ECHO-B 的 RBJ / 固定 S=1 架式与 Q22 实现；Q=0.8 编译为 0.80078125。78 Hz 是在 60–80 Hz 低架、90–110 Hz 峰值的相近组合中，为五采样率数值一致性选出的频率，不是从耳机测量精确定位出的共振点。[公式依据](https://www.w3.org/TR/audio-eq-cookbook/) · [候选扫描记录](../analysis/riff-impact-v5-candidate-scan.json)

## 整体电平与试听

遵循[当前仓库整体增益约定](../../../../presets/README.md#整体增益约定)，文件省略 `output_gain_db`，缺省为 **0 dB**；不是保留设备当前电平。历史文档中的 −20 dB 是当时设置，本次没有自动套用。建议导入后手动设置 **−3 dB**，五采样率稳态模型的最高输出约 **−2.05 dB**。ECHO-B 的整体衰减在末级，不能据此保证前级节点或瞬态不会削波。

固定当前 Kadenz 导管、耳套与密封，选择熟悉的快速 riff、双踩和贝斯同奏片段。与无 EQ 对照时使用相同整体增益，再匹配听感响度。先判断吉他音高和节奏是否更好跟，再判断鼓与贝斯是否保留力量；不要因更响而判定更清晰。

- 深低频支撑不足：只将低架 −1.2 改为 −0.6 dB。
- 鼓点遮住 riff：只将 100 Hz 从 +1.2 改为 +0.7 dB。
- 吉他中频变拥挤或有鼻音：先将 900 Hz 从 +0.6 改为 0 dB。

每次只改一处，并重新检查五采样率预览。V5 是新的偏好试验，不表示听感已经优于旧方案。未执行设备读取、写入或主观试听。
