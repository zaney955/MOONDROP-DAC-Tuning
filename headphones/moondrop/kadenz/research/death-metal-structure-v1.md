# 密集金属编曲的调音设计

适用于密集死亡金属和葬礼厄运的音色设计原则。具体参数以[预设 JSON](../../../../presets/kadenz-death-metal-structure-v1.json)为准，适用条件见[Kadenz 指南](../tuning-guide.md)。

## 全频段评估依据

音乐结构的清晰呈现优先于低频冲击、音量刺激和声音厚度。目标是让吉他 Riff 与声部变化、鼓组转换和贝斯线条更易追踪，同时保留 Evoken、Esoteric 等葬礼厄运的低频深度、声音密度与缓慢展开的层次。

Kadenz 两套官方测量的共同轮廓是向深低频倾斜的低频量感，以及约 3 kHz 的宽幅存在感隆起；200–500 Hz 没有共同的宽幅隆起。它们是耳模拟器上的响应，不是偏离中性的误差，不能直接削平。测量依据见[统计表](../analysis/summary.md)。

这次从 20 Hz–20 kHz 重新选择滤波，不以原有三段为约束。两套测量分开解读，不平均、不互为目标，也没有引入未经校验的中性目标。外部方法来源、逐区证据与限制见[全频段证据复核](full-band-evidence-review.md)。官方声学数据实际止于 19,896.974609 Hz；20 kHz 端点只计算 DSP 响应，不补造耳机测量。

| 区域 | 观察、设计意图与取舍 |
| --- | --- |
| 20–60 Hz | 两套均有低频底座；按清爽偏好轻微低架减量，不新增深低频提升或高通。保留延伸和大部分重量，控制总低频比例；这属于口味选择，非测量证明的过量校正 |
| 60–120 Hz | 原响应向上低频逐渐回收；让低架与峰切平缓衔接，避免只在中间深挖、使深低频相对更突出 |
| 120–250 Hz | 局部浅切，控制底鼓与贝斯重叠时的量感；相比上一版减少局部削减深度，与前段共同构成连续低频减量 |
| 250–500 Hz | 没有共同宽幅隆起，不另加“去浑浊”滤波；控制前段尾部，保住低音弦、军鼓和慢速重音的实体感 |
| 500 Hz–1 kHz | 小幅宽带补充 Riff 和乐器主体；测量架之间有差异，不称为共同中频缺陷的补偿，避免鼻音与箱声 |
| 1–2 kHz | 不追加存在感提升；由中频段与上中频段自然过渡，避免密集失真吉他过度前凸 |
| 2–4 kHz | 两套共有宽幅存在感峰；温和缓解压迫，保留大部分耳道增益轮廓，不深挖峰顶 |
| 4–6 kHz | 峰后已经回落，没有匹配目标证明此处不足；不因追求颗粒感自动提升。控制前段尾部，避免损失攻击轮廓后再用新增提升抵消 |
| 6–10 kHz | 不补约 6–7 kHz 窄谷，不把约 8 kHz 视为必切峰；未知佩戴和实际刺点时保留，不为增加段数制造修正 |
| 10–20 kHz | 两套局部响应差异大，不用高架或窄带提升补空气感/深谷，也不为柔和而整体压暗。长混响与空间层次先通过低频和中频平衡争取 |

## 最终设计与候选取舍

采用一段固定 S=1 的低架和三段标准 RBJ 峰值滤波。深低频总量、上低频局部量感、中频主体和存在感各有独立作用；更高频的保留来自逐区评估，而非未作检查。没有为了用满八段新增高频滤波。全部音色增益按 0.1 dB 步进设置，具体参数以预设为准；小数是可复现的设定值，不代表听感或测量精确到 0.1 dB。

候选计算比较了原局部上低频切、向更低频扩宽的单峰切，以及轻低架配较浅峰切。扩宽单峰会更多削减底鼓的重音区域，但仍几乎不动最深处；最终选择低架配浅峰切，将小幅减量连续分配到低频，减轻上一版局部凹陷。中频提升中心稍下移、力度略减，使主体支撑不过度集中于更高的中频；存在感段重新选择宽度和力度，并检查其对 4–6 kHz 的尾部影响。它们是符合偏好的取舍，未经过试听排名，不是算法找到的唯一最优解。

低频候选还按五种采样率检查实际 Q22 曲线：部分看似更轻的低架在最高采样率下产生明显额外减量，部分峰切也出现可见偏差，因此未只按参数标签选择。最终低架和峰切保留了预期的小幅、连续响应。整体输出数字增益沿用当前设置，用于听音电平和最终幅度余量，不属于音色校正。

这是基于官方测量和个人偏好的试听假设，没有匹配测量架的个人目标曲线，也没有用户的耳内测量。EQ 不能分离混音中已经重叠的声部，也不等于改善单元机械速度或扩大真实声场。导管、耳套与佩戴条件未知，因此不做与特定配件对应的窄带高频修正。

## 验收要求

预设须通过五种采样率的范围、稳定性与频响检查；写入须具有完整保存 ACK 和匹配的读回。模拟输出、实际听感和物理拔插保持需要分别验证，不能由编译成功或参数标签推断。

当前预设的[离线响应报告](../analysis/death-metal-structure-v1.json)和[五采样率曲线数据](../analysis/death-metal-structure-v1.csv)由 `python3 tools/analyze_kadenz.py` 在项目根目录生成。报告包含源文件与写入计划哈希、去除整体增益后的音色响应、全频段十个区间的平均/最小/最大变化、最终输出范围，以及整体增益之前各级联前缀的最大幅度；检查网格为 20 Hz–20 kHz 的 6001 个对数频率点，区间极值还纳入精确边界。区间均值是对数频率上的 dB 均值，不是响度或声能。采样频响不是瞬态峰值或硬件内部不削波的证明。

## 试听方法

固定佩戴条件，选同一录音片段，匹配听感响度后比较：

- 高速双踩与 Blast Beat 中，是否更容易听清每次落点、军鼓转换和 Riff 变化，而非仅仅听起来更亮。
- 多把失真吉他与贝斯同时进入时，能否追踪声部与低音走向；吉他低音弦和军鼓是否仍有实体感。
- 葬礼厄运的低频持续音、慢速重音与长混响是否保有重量、氛围和层次，而非整体变薄。
- 镲片和拨弦是否自然；长听出现硬、砂、鼻音或疲劳时，一次只撤回一个变化。

深处持续音失去底座时，优先减小低架减量；底鼓或吉他低弦失去肉感时，优先减小局部上低频削减。中频鼻、箱或拥挤时先减小提升；存在感段使拨弦、军鼓失去攻击轮廓时先减小该段削减。以上是试听后的调整路径，不是已观测到这些问题。

试听数据保存在 `listening/`，包含配置快照、曲目片段、响度匹配方式与取舍。文档只说明设计原则和试听方法。
