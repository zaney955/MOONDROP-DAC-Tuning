# Kadenz · 死亡金属结构清晰 V1

日期：2026-10-29。配置：[kadenz-death-metal-structure-v1.json](../../../../presets/kadenz-death-metal-structure-v1.json)。这是根据用户明确偏好与 Kadenz 官方测量轮廓设计、已写入 ECHO-B 的第一版；听感仍需用户确认，导管及耳套组合尚未记录。

## 设计目标

用户优先辨认密集编曲中的吉他 Riff、不同声部、贝斯线条和鼓组变化，希望整体中性偏清爽，保留重量和力量，避免肥厚低频、V 型中频凹陷和靠高频刺激制造的解析感。同时兼顾 Evoken、Esoteric 等葬礼厄运的深低频、密度、空间氛围与缓慢发展的层次。

本版主要调整频谱平衡，以减少部分中低频厚重感、突出中频线条的相对可辨识度。EQ 无法把混音中已经糊在一起的声部分离出来，也不等于改变单元的机械速度或真实扩大声场。这里把“更紧、更清楚、更有层次”作为待试听目标，不写成已测得的性能改善。

## 参数与取舍

音色设计增益 `preamp_db` 为 **−2 dB**。当前预设还包含 `output_trim_db: -18`，合并增益为 **−20 dB**；下文原设计的数值及历史验收未计入这项新增输出衰减。四段均为峰值滤波，未使用低架或高架。表格按实际发送顺序列出，先放两段削减，再放两段提升；硬件内部余量尚未测量，不能仅靠排序保证内部各级都不会溢出。

| 段 | 频率 | 增益 | Q（输入值） | 目的 |
| --- | ---: | ---: | ---: | --- |
| 1 | 180 Hz | −2 dB | 0.9 | 温和收紧上低频/中低频厚重感，为连续双踩、低音吉他和贝斯的轮廓留出相对空间；不用低架削掉整个低频底座 |
| 2 | 3000 Hz | −1 dB | 1.2 | Kadenz 原有约 3 kHz 的宽幅隆起只轻收一点，降低密集失真及高声部可能带来的压迫，同时保留存在感 |
| 3 | 900 Hz | +1 dB | 0.8 | 给中频主体小幅支撑，希望吉他层次及贝斯谐波更容易追踪，避免切低频后显得干薄 |
| 4 | 5200 Hz | +1 dB | 1.4 | 小幅补充拨弦、鼓击轮廓；不大范围抬高高频，也不追踪未知的个人耳道窄峰 |

第 5–8 段直通，第 9 段实现全局衰减；Q 由工具量化到 1/256。保留 8–20 kHz 基本原貌，没有为追求“空气感”增加高架，也没有根据两套不一致的高频测量强补凹谷。

四段会相互影响，实际变化不等于各段中心增益的简单孤立读数。下表为 **48 kHz、量化后、去掉全局 −2 dB 的音色变化**，不是耳内实测：

| 频率 | 相对原始 EQ 的音色变化 |
| --- | ---: |
| 30 Hz | −0.07 dB |
| 50 Hz | −0.20 dB |
| 100 Hz | −0.87 dB |
| 180 Hz | −1.94 dB |
| 300 Hz | −0.87 dB |
| 500 Hz | +0.13 dB |
| 900 Hz | +0.84 dB |
| 1500 Hz | +0.35 dB |
| 3000 Hz | −0.61 dB |
| 5200 Hz | +0.72 dB |
| 8000 Hz | +0.25 dB |
| 10000 Hz | +0.11 dB |
| 16000 Hz | +0.02 dB |

这让深低频基本保留、180 Hz 适度收敛，而 500–1500 Hz 仍有主体支撑；高频变化小于单段表格可能给人的第一印象。所有频点在原设计中叠加 −2 dB 全局衰减；当前配置还需再叠加 −18 dB 输出衰减才是实际数字增益，因此比较音色时要匹配听感响度。

## 验证与设备状态

- 44.1 / 48 / 96 / 192 / 384 kHz 五套系数全部通过 24 位范围、量化后极点稳定性检查。
- 在每个采样率的 20 Hz–20 kHz 12,001 个对数频点上检查组合响应，并与使用相同量化 Q 的浮点峰值公式比较；最大系数量化误差约 0.060 dB（192 kHz）。这不包含声学测量误差。
- 五种采样率在检查网格上的总响应峰值均低于 −1.15 dB；另检查了 DC 至奈奎斯特频率的 16,001 点。网格检查与最终频响余量不等于已验证硬件内部溢出、所有瞬态峰值或模拟失真。
- 设备接受了 56 条操作，包括保存命令。首次写后读取遇到 `kIOReturnNotReady`，保留了不完整读取记录，随后仅重读，没有重复写入。
- 重读确认模式、9 段参数标签、9 段当前运行系数均与计划一致，匹配 **48 kHz** 系数。物理拔插持久化和实际听感未在本次验证。

## 第一轮试听重点

用相同片段、匹配听感响度比较 `original-minus-16db` 与本配置。前者总增益 −16 dB，本配置的固定增益为 −20 dB，且频谱变化还会影响主观响度，不应直接以相同手机音量比较。先听高速密集死亡金属，再用自己熟悉的 Evoken / Esoteric 段落确认没有丢失慢速重音的底座与氛围。

| 需要验证的问题 | 若不合适，下版优先只改这一项 |
| --- | --- |
| 双踩更易辨认，但吉他低音弦或军鼓主体变瘦 | 180 Hz 从 −2 改为 −1 dB |
| Riff 主体更清楚，但出现鼻音或中频拥挤 | 900 Hz 从 +1 改为 0 dB |
| 拨弦更清楚，但镲片、失真毛刺容易累 | 5200 Hz 从 +1 改为 0 dB |
| 人声/失真仍在 2–4 kHz 顶耳 | 试听定位后，再考虑 3000 Hz 从 −1 改为 −2 dB |
| 葬礼厄运的深度尚在，但厚重氛围减少 | 先减弱 180 Hz 削减，不急于大幅增加深低频 |

上述是下一轮试验方向，当前只保存并写入 V1。后续每版另存文件，并记录具体录音、佩戴条件和得失，避免覆盖已验证的基准。
