# 密集金属调音示例

本文保留原设计与分析条件；现行文件和历史报告的区别见[型号索引](../README.md#预设与分析报告)。

此示例面向密集死亡金属与葬礼厄运，尝试兼顾 Riff 走向、声部辨识和低频重量。具体参数以[预设 JSON](../../../../presets/echo-b/moondrop/kadenz/kadenz-death-metal-structure-v1.json)为准。它来自官方测量轮廓与个人试听反馈，不是面向所有佩戴者的目标校正。

## 设计依据

两套官方测量分别解读，不平均、不互为目标。相对 500 Hz 的电平不是偏离中性的误差；佩戴、高频和目标曲线的适用限制见[Kadenz 指南](../tuning-guide.md)与[外部资料](sources.md)。

| 区域 | 设计选择与局限 |
| --- | --- |
| 20–120 Hz | 依据已应用前版后仍偏薄的反馈，将低架改为适度提升，增加底部和底鼓重音的重量；这是口味选择，不是测量证明低频不足 |
| 120–250 Hz | 撤掉局部削减，保留低架尾部的自然过渡，恢复贝斯、低音弦与鼓身重量；不另加局部提升，复听时检查堆积和遮蔽 |
| 250–500 Hz | 测量没有共同宽幅隆起；小幅支撑用于厚度取舍，不称为修复测量缺陷 |
| 500 Hz–2 kHz | 温和支撑主体，避免中频鼻、箱或过度前凸；两系统中频差异不作为精确补偿依据 |
| 2–4 kHz | 轻收存在感压迫，保留大部分耳道增益和攻击轮廓 |
| 4–10 kHz | 不为增加颗粒感自动提升，也不把约 8 kHz 当作固定必切峰；检查前段滤波尾部影响 |
| 10–20 kHz | 不反向拟合局部深谷，不以整体压暗制造厚度；官方测量实际止于约 19897 Hz |

当前配置使用低架与宽带峰值滤波。厚度修订的依据是个人试听中“偏薄”的反馈；增加后的实体感能否兼顾密集声部辨识，仍需匹配响度复听，不能从曲线保证。EQ 不能分离混音中已重叠的声部，也不等于提高单元机械速度或扩大真实声场。

此前先减小上低频削减、增加下中频支撑，之后本人明确确认已经应用那组五段参数，低音仍偏薄、缺少厚重感。因此本次直接将低架从减量改为提升，并撤掉上低频削减；下中频、中频主体、存在感及整体输出参数沿用，以便集中判断低频比例。新版改为四段，不保留无作用的零增益占位。候选按五种采样率的量化曲线筛选，避免仅按增益标签判断实际提升。本人尚未对本次新版复听，不能把前版反馈当作新版已验证的听感。

## 验证与复算

[离线报告](../analysis/death-metal-structure-v1.json)和[五采样率曲线](../analysis/death-metal-structure-v1.csv)由 `python3 tools/analyze_kadenz.py` 生成，包含源文件与计划哈希、去除整体增益后的音色响应、频段变化、最终输出和级联前缀幅度。

网格为 20 Hz–20 kHz 的 6001 个对数频点，区间统计纳入精确边界。均值不是响度或声能，采样响应也不是硬件内部或瞬态无削波的证明。编译校验、保存 ACK、设备读回、模拟输出、听感与拔插保持需要分别验收。

## 试听取舍

固定佩戴和响度，用相同片段比较：

- 高速双踩与 Blast Beat 中的落点、军鼓转换和 Riff 是否更易追踪。
- 多把吉他与贝斯同时进入时，是否保留声部走向、低音弦和鼓身重量。
- 慢速重音、低频持续音与长混响是否有层次，镲片和拨弦是否自然。

新版复听先确认低频持续音、慢速重音和双踩是否有足够重量，再检查同段中的 Riff 和贝斯走向。若底鼓与贝斯持续堆积、盖住音符变化，先小步减小低架提升；若低频重量合适而吉他箱声或拥挤增加，再单独减小下中频支撑；攻击轮廓不足时再考虑减小存在感削减。每次只改变一个因素，使用多段熟悉录音和重复佩戴判断。记录方法见[试听指南](../tuning-guide.md#比较与记录)。
