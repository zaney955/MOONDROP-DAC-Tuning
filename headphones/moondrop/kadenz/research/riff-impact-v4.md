# Kadenz：Riff 线条与适度冲击 V4

本文保留原设计与分析条件；现行文件和历史报告的区别见[型号索引](../README.md#预设与分析报告)。

希望吉他 riff 的音高、节奏和推进容易跟住，鼓与贝斯有适度重量，同时保留密集编曲中的层次。这份配置只少量补充低频支撑，主要提升集中在 60–120 Hz；不额外堆高中低频，也不预设要削弱吉他的存在感。

2026-10-31 定制试听起点：[配置 JSON](../../../../presets/echo-b/moondrop/kadenz/kadenz-riff-impact-v4.json)。已完成离线编译与全频段响应检查，未向设备写入、未试听、未进行模拟输出测量。V4 表示另存的新方案，不表示听感已优于 V3。

## 整理后的听音偏好

我最看重吉他 riff 是否容易辨认：能跟住音高起伏、节奏变化，以及它与贝斯、鼓之间的配合。我喜欢死亡金属用少数几件乐器构成复杂而协调的音乐，希望听清编曲的层次和发展，而不只是听见更多细节。

低频需要有适度的冲击、震感和支撑，但不必让所有作品都显得厚重，更不能盖住吉他线条。Suffocation 的第一、第三张专辑已经很接近我的理想听感：riff 清楚，低频有力，密集段也不刺耳；Cryptopsy 的《Slit Your Guts》在我的听音条件下则显得偏轻、偏瘪。

这些差异首先是不同录音在同一套听音系统中的表现，不能直接归结为 Kadenz 缺低频。调音希望温和改善偏轻录音的重量，同时尽量保留原本满意录音的平衡；如果两者冲突，优先保留 riff 的辨识度。

## 参数及当前算法

| 类型 | 频率 | 增益 | Q / S | 目的 |
| --- | ---: | ---: | --- | --- |
| low_shelf | 110 Hz | +0.6 dB | S=1，JSON q=1 | 少量增加底部支撑 |
| peak | 90 Hz | +1.0 dB | Q=0.9 | 主要增加低频落点与冲击，试听确认是否掩盖音符 |
| 整体输出 | — | −20 dB | 第 9 段 | 沿用项目当前默认值 |

使用当前 `tools/preset.py` 的 RBJ 峰值 Q、固定架式 S=1 和有符号 24 位 Q22 实现。Q=0.9 编译后为 0.8984375；架式频率是增益中点。定义参考 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)（2026-10-31 核查）。参数不能直接视为官方 App 中的同名曲线。

末级 −20 dB 不是前级衰减，最终响应低于 0 dB 不证明内部级联或瞬态没有溢出。试听时也不应通过补偿音量把更响误认为更清晰。

## 20 Hz–20 kHz 的取舍

依据本地[官方测量](../measurements/README.md)与[统计](../analysis/summary.md)，两份原始文件及处理后数值已重新核对。5128、4128 分开判断，不平均、不直接相减，也没有引入未经校验的目标曲线。

| 区间 | 本版判断 |
| --- | --- |
| 20–60 Hz | 官方数据已有明显深低频，仅温和补充，不以持续低频量感替代冲击 |
| 60–120 Hz | 本次主要调整区；根据个人听感选择，非测量证明的耳机缺陷 |
| 120–250 Hz | 允许滤波器自然衰减的少量提升，不另加厚度段 |
| 250–500 Hz | 两套测量没有共同宽幅隆起，不默认挖空或补厚 |
| 500 Hz–2 kHz | 本次没有可定位的音色问题，保留主体轮廓 |
| 2–4 kHz | 虽有约 3 kHz 宽峰，但不能当作需要削平的缺陷；本次未提出普遍刺耳问题，不设置削减段 |
| 4–8 kHz | 不靠增加拨弦或镲片亮度来替代 riff 辨识度 |
| 8–20 kHz | 测量间差异与个人适用性不确定，不反向拟合窄峰谷；实测仅到 19896.974609 Hz |

对《Slit Your Guts》的描述只采用本次明确给出的“偏轻、偏瘪”，不沿用旧研究文档中的其他器材或刺激感描述作为新增调整依据。没有音源、版本和相同条件下的对照，不能断言是其混音、母带或某个具体频段导致。

相对工作区 V2，低架 +1.0 → +0.6 dB、120 → 110 Hz，90 Hz 峰值 +1.4 → +1.0 dB，并撤掉 3.2 kHz −1.1 dB。相对手动保存的 V3，低架同样减小，90 Hz 峰值 +0.5 → +1.0 dB，撤掉 3.2 kHz −0.4 dB。V4 将新增低频更集中于冲击区域，保留原来的上中频轮廓；这只是设计意图，需要试听确认。

## 录音与设备影响、试听方法

静态 EQ 对所有录音施加相同频率变化，不能识别哪一首需要加重，也不能分离同一频段内的吉他、鼓与贝斯。它可以改变频谱平衡，但不能恢复录音中已经混在一起或缺失的信息，亦不承诺耳塞复制音箱作用于身体的震感。

设备侧先固定导管、耳套、密封、播放器音效与音量比较方式；如果同一片段随重新佩戴明显变薄，优先排查佩戴。如果固定条件后主要是特定录音偏薄，把它视为录音与系统的交互，不据此继续提高所有作品的低频。

在编辑器选择本版，或导入 JSON。先用无音色 EQ、同为 −20 dB 输出的配置对照，并尽量匹配听感响度。同一系统音量数字不等于同响度。

1. 先听 Suffocation 第 1、3 专熟悉的 20–30 秒：riff 是否仍易跟住，快速鼓点是否堆积，贝斯音高是否更难分辨。原本满意的平衡是约束。
2. 再听《Slit Your Guts》相同长度的片段：重量是否增加，代价是否是吉他音符或节奏变难跟。两项分别判断。
3. 如果原本满意的录音变拥挤，先只把 90 Hz 从 +1.0 降到 +0.5 dB；若只是持续底部量感过多，则单独试低架 +0.6 → +0.3 dB。修改后重新编译，不把这些建议当作已验证预设。
4. 如果仍偏薄，但满意录音已经不能再加低频，应保留两种播放选择，而不是继续增加统一补偿。记录具体版本、片段时间、改善与损失后再迭代。
