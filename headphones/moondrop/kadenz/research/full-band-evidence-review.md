# Kadenz：20 Hz–20 kHz 调音证据复核

本次复核用于死亡金属结构辨识与葬礼厄运重量/氛围之间的取舍。这里提供全频段决策依据；最终参数以[预设](../../../../presets/kadenz-death-metal-structure-v1.json)为准。未试听、未做耳内实测、未操作耳放。

## 证据如何使用

**测量观察：**使用本项目保留的官方 5128、4128 原始频响与[可复算统计](../analysis/summary.md)，两条曲线分别以 500 Hz 对齐，只比较各自轮廓。相对 500 Hz 的抬升不是相对中性目标的误差；不平均两套测量，不把两者差值当成 EQ。官方数据出处、导出条件及原文件链接见[测量说明](../measurements/README.md)。本次网页复查未能访问该 CDN/API，数值依据为已归档文件，而非宣称重新下载成功。

**方法证据：**B&K 说明 4128 与 5128 的耳道/声学负载设计不同，5128 依据平均人耳几何及阻抗设计。这支持区分测量条件，不能证明任一模拟器就是本用户耳道。[B&K：High-frequency HATS, why?](https://www.bksv.com/de/knowledge/blog/sound/high-frequency-hats)

GRAS 的仿真研究表明，耳道长度影响共振位置，容积也会改变响应；泄漏与插入位置需要纳入测试。因此，共同出现的高频局部峰仍不足以确定个人修正频率；也不能把两系统差异全归因于“耳道形状”。[GRAS：The Impact of Ear Canal Geometry on In-Ear Headphone Testing，尤其第 5、9 页](https://www.grasacoustics.com/fileadmin-gras/Industries/Consumer_Audio___Electronics/GRAS_Ear_Canal_WP-2024-10__1_.pdf)

**偏好证据：**用户明确偏好清爽、结构清楚、低频受控且有重量。研究作者报告的调整实验显示，低频/高频偏好受个人与节目影响；它不提供 Kadenz 或死亡金属的唯一参数。[Sean Olive：Factors that Influence Listeners’ Preferred Bass and Treble Levels in Headphones](https://seanolive.blogspot.com/2015/11/factors-that-influence-listeners.html)

## 全频段决策

| 区域 | 两套测量中的观察 | 对本用户的调音判断（推断与偏好选择） |
| --- | --- | --- |
| 20–60 Hz | 两套都有向底部倾斜的低频量感；均值相对各自 500 Hz 约 +6.81 / +6.27 dB | 保留延伸，不用高通去掉底座，也没有必要再增加深低频。可把“保持”和“极轻低架减量”列为候选；后者是控制总体低频支配的口味选择，不能说测量证明此处过量。 |
| 60–200 Hz | 量感逐渐回收，但仍高于中频低点；100 Hz 局部形状在两套间有差别 | 收紧的主要候选区。宽幅浅切可减少量感；低架与局部峰切须看组合曲线。只深切约 150 Hz 而保留全部深低频，可能让底部与中频之间的落差更大；轻低架配较浅峰切可作为另一方案，但不能把两段各自的削减量简单相加成最终响应。 |
| 200–500 Hz | 两套没有共同的宽幅隆起，均值仅约 +0.72 / +0.93 dB | 不预设这里“浑浊”，不额外挖坑。前段低频切的尾部应受控，避免吉他低弦、军鼓和慢速重音失去实体感。也不因“厄运需要厚度”无依据大幅补起。 |
| 500 Hz–1.5 kHz | 两套最低区/上升转折不同，800 Hz–1 kHz 也有明显跨系统差别 | 可围绕中频主体做小幅宽带调整以符合偏好，但不是对共同缺陷的精确补偿；提升过量可能鼻、箱、拥挤。应检查它与低频切及上中频切的实际叠加。 |
| 1.5–4 kHz | 两套都向约 3 kHz 宽峰上升；1 kHz 到 3 kHz 的上升约 9.9 dB，轮廓接近 | 可小幅降低压迫感；保留大部分耳道增益及攻击轮廓。强挖存在感可能损失拨弦、军鼓与声部辨识，不能将原图的峰高作为削减量。 |
| 4–6 kHz | 从存在感峰逐渐回落；未建立同架目标差值 | 不因“颗粒、瞬态、分离”自动提升。上中频削减的尾部若明显暗化这里，优先改变前段宽度/力度，而非用新增提升互相抵消。小幅提升只应视为需试听证实的候选。 |
| 6–9 kHz | 两套在约 6.5–6.7 kHz 附近回落，再在约 8 kHz 回升 | 不补窄谷，也不把约 8 kHz 当作必切点。用户没有报告定位明确的镲片刺点，故不足以默认增加陷波；若未来确认多首录音重复刺耳，再处理本人实际刺点。 |
| 9–12 kHz | 500 Hz 对齐后，两套在 10、12 kHz 分别相差约 6.1、10.9 dB | 不据单条曲线补“空气感”。高架提升会改变镲片/嘶声平衡，且不是空间定位或分离的保证。 |
| 12–20 kHz | 局部峰谷不一致；官方数据实际上止于 19,896.97 Hz | 保留现状，不反向拟合深谷，不补造 20 kHz 测量值。DSP 响应可计算至 20 kHz，但不把它说成有对应声学实测。 |

## 建议取舍

全频段复核并不要求每个区域都新设滤波。值得优先比较的是：原来的局部上低频削减，与“极轻低架减量＋较浅局部上低频削减”对整体低频坡度的不同影响；同时重新选择中频主体与存在感的力度和宽度。对这位用户，后者有合理的口味依据，可以让低频控制覆盖底部而非只在中间挖一块，但必须保留深低频相对中频的明显底座，避免过度减量。

现有证据不足以要求额外调整 4–20 kHz。默认保留高频是完成评估后的选择，不表示这些区域不重要、没有差异或无法调。若候选方案需要补偿前段带来的高频轮廓损失，应先检查前段设计，而非为了段数而增加滤波。

所有小数增益都是可复现的设置值，不是测量给出的唯一最优解，也不表示个人声学响应具有 0.1 dB 的准确度。最终需要以五采样率的量化后组合曲线、内部级联前缀幅度，以及匹配响度的熟悉录音试听分别验收；离线稳定不等于硬件内部或瞬态绝无削波。
