# NICEHCK / 原道十周年纪念版

资料核对日期：2026-11-01。型号为 **10th Anniversary Edition 平头耳机**，包含蓝／红色的 3.5 mm 无麦、有麦和 Type-C 有麦版本；本档案测量不与其他原道型号混用。[官方商品页](https://www.nicehck.com/products/yuandao-10th)

用户使用 **3.5 mm 版本＋ECHO-A、全包海绵套**，目标为温和均衡。耳放数字读回与耳机声学证据分别记录。

## 海绵与版本不能混用

官方包装图直接说明海绵用于增加低频、优化佩戴；见[包装及海绵安装说明原图](https://cdn.shopify.com/s/files/1/0865/0850/3331/files/12_4bfb0b4b-2e94-43aa-b5e0-4c67fc74e7e0.jpg?v=1773218483)。该说明没有给出海绵前后的增益数值或频率范围，所以不能把无海绵图当成用户全包海绵的精确响应，也不能按固定若干 dB 自动换算。

3.5 mm 耳机自身没有 USB DSP。官方的[DAC 说明图](https://cdn.shopify.com/s/files/1/0865/0850/3331/files/07_5da945f6-a44e-42d0-b966-53d07ed656b5.jpg?v=1773218492)明确将内置 DAC、最高 32 bit/384 kHz 解码及 DSP 功能限定在 **Type-C 版本**。用户把 3.5 mm 版本接到 ECHO-A 时，处理发生在 ECHO-A；不能据此推断该耳机 Type-C 版本的默认 DSP 状态、系数率或保存流程。

## 官方 App 与预设

官方[PEQ 说明图](https://cdn.shopify.com/s/files/1/0865/0850/3331/files/08_12470106-190e-429e-9eb9-590c17266da4.jpg?v=1773218480)说明十周年 **Type-C** 版本支持 8 段参数 EQ。图中底部同时注明，有线耳机的 App DSP 控制目前只支持 Android，iOS 与 HarmonyOS 暂不支持。与此同时，当前[官方 App 下载页](https://www.nicehck.com/pages/app)已经列出 Android 和 iOS 17.0＋安装入口。两项证据应分别理解：**App 可安装，不等于这一有线型号的 DSP 功能可用**。本仓库没有进行手机实机兼容性验收。

制造商于 2026-07-15 的[原始公告](https://www.sina.cn/news/detail/5320954000443606.html)宣布 App 2.3.7 加入十周年官方音效，包括悔恨之泪、摇滚现场、流行人声、均衡杂食、ACG，以及油兔几参与的 DSP 仙人特调。公告可证明这些预设被官方发布，未提供本轮可复算的滤波器参数；本仓库没有导入、反推或声称复现这些官方预设。

## 温和试听起点与历史验收

[现行预设](../../../presets/echo-a/nicehck/yuandao-10th/yuandao-10th-foam-balanced-v1.json)使用两段微调：

| 类型 | 频率 | 增益 | 参数 | 意图 |
| --- | --- | --- | --- | --- |
| 低架 | 110 Hz | ＋1 dB | S=1 | 少量补充低频支撑 |
| 峰值 | 1600 Hz | −1 dB | Q=1 | 轻收宽中频隆起 |

这是依据无海绵官方图和用户温和目标设计的试听假设，不是全包海绵 AutoEQ 或个人耳内校正。整体前级由用户设置，见[配置约定](../../../presets/README.md#整体增益约定)，不视为耳机音色修正量。

试听时固定海绵、摆位和录音，先匹配听感音量再比较人声、鼓、贝斯与吉他。低频已足时减少低架，人声变空或后退时先撤销 1600 Hz 削减。缺少佩戴一致性和失真数据时，不按深低频滚降或高频凹陷作大幅反向提升。

[初次实机记录](../../../runs/20261101T043919.313826Z-echo-a-yuandao-10th/README.md)及[网页验收](../../../docs/validation-20261101.md#echo-a-网页实机验收)记录的是对应时刻的系数、参数与电平，不代表当前设备状态；模拟频响、实际电平和主观改善未由这些读回证明。
