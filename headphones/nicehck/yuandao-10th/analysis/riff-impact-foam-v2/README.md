## 基于新 CSV 得出的检查结果

依据[官方图像数字化 CSV](../../measurements/digitized/README.md)，无海绵图在 1.6 kHz 约比 1 kHz 高 4.55 dB，3 kHz 约为 −0.24 dB。频响未做感知目标补偿，不能将两者差值直接视为需要全部消除的误差。

实际编译 v1 后，1600 Hz 的净 EQ 仅 −0.059 dB：原单段 −1.2 dB 大部分被邻段提升抵消。v1 的说明曾明确记录这一结果，因此不是编译错误；本次重新评估它是否充分服务于用户希望辨认不同 riff 的目标。

v2 选择温和降低 1.6 kHz 相对于 3 kHz 的突出程度，维持 3 kHz 附近轮廓。官方裸塞参考图＋数字 EQ 模型中，1.6 kHz 与 3 kHz 的幅度差从 v1 的约 3.01 dB 收至 v2 的约 1.92 dB；**这只是频段相对关系变化，不是“清晰度提升 1.09 dB”，也不是海绵实测。**

官方海绵说明只支持“提升低频、优化佩戴”的方向，未提供增益数值；因此将 90 Hz 的提升温和收小是避免与海绵增厚叠加的试听选择，不是测得戴海绵恰好多出 1 dB。[官方包装原图](https://cdn.shopify.com/s/files/1/0865/0850/3331/files/12_4bfb0b4b-2e94-43aa-b5e0-4c67fc74e7e0.jpg?v=1773218483)

| 峰值频率 | v1 增益 / Q | v2 增益 / Q | 意图 |
| --- | --- | --- | --- |
| 90 Hz | +3 / 0.8 | +2 / 0.8 | 保留鼓与贝斯支撑，降低额外低频量感 |
| 250 Hz | −1.8 / 0.9 | −1.5 / 0.9 | 低频提升收小后，少削一点主体；净削减基本不变 |
| 850 Hz | +0.8 / 0.8 | +0.5 / 0.8 | 减少中频提升的叠加，避免与 1.6 kHz 调整互相抵消 |
| 1600 Hz | −1.2 / 1.1 | −2.2 / 1.2 | 让这一带产生温和净削减，保留宽峰而非抹平 |

## 叠加 CSV 的正确用法

[comparison.csv](comparison.csv) 包含原图估算、v1/v2 的数字 EQ、两者差分，以及“无海绵参考＋EQ”模型。最后两列各自按 1 kHz 归零，便于比较形状；归零并不等于匹配听感音量。不能将它们重命名为“全包海绵最终频响”。

没有全包海绵原始测量、个人耳内响应或适用于当前夹具的已选目标曲线，所以本次没有执行自动目标拟合，也没有用“曲线更平”证明更好听。B&K 说明耳机测量需要考虑耳廓和声学负载；图中隆起并不自动等于缺陷。[B&K 测量说明](https://www.bksv.com/en/knowledge/applications/electroacoustics/headphone-testing)

## 电平、验证与试听

v2 保持当前仓库约定：省略 `output_gain_db`，缺省编译 **0 dB**。20–20000 Hz、12,001 点扫描的净 EQ 范围为 **−1.257 至 +1.756 dB**。建议手动设置数字前级 **−3 dB**，模型输出峰值约 **−1.244 dB**；稳态频响检查不保证所有信号或内部节点都无削波。

与 v1 对比时可以先将两者整体增益都设为 −4 dB，再小幅匹配听感音量。固定海绵与摆位，听同一段快速 riff＋双踩＋贝斯：优先判断音高和节奏是否更容易跟住，其次判断低频是否仍有支撑。不要仅凭更亮、更响决定优劣。

- 若力量不足：仅将 v2 的 90 Hz 从 +2 调至 +2.5 dB，再预览峰值。
- 若吉他变远或存在感减弱：先将 1600 Hz 从 −2.2 改至 −1.7 dB。
- 若军鼓、吉他边缘或人声太冲：将 3000 Hz 从 +2.2 改至 +1.5 dB。
