# JSON 格式

每个 JSON 是一份完整听音设置，写入时整体替换设备 EQ。名称、用途和具体数值只维护在文件内；用 `python3 tools/preset.py list` 查看列表。操作步骤见[操作指南](../docs/operations.md)。

| 字段 | 含义与范围 |
| --- | --- |
| `version` | `1` |
| `device` | `MOONDROP ECHO-B`，指耳放而非耳机 |
| `name` / `description` | 显示名称与用途；名称不能为空 |
| `preamp_db` | EQ 设计增益，−60 至 0 dB，可用小数 |
| `output_trim_db` | 必填的额外输出衰减，−40 至 0 dB，可用小数；`0` 表示无额外衰减 |
| `filters` | 最多 8 段，空数组表示不改变频响形状 |

总增益为 `preamp_db + output_trim_db`，不得低于 −60 dB。第 9 段实现这项固定衰减。未知字段、缺失输出衰减或非法数值会停止编译。

每个滤波器包含以下字段：

| 字段 | 范围 |
| --- | --- |
| `type` | `peak`、`low_shelf`、`high_shelf` |
| `frequency_hz` | 20–20000 的整数 Hz |
| `gain_db` | −12 至 +12 的整数 dB |
| `q` | 峰值为 0.1–10，量化到 1/256；架式必须为 `1`，对应斜率 S=1 |

限制以[编译器](../tools/preset.py)为准。系数溢出或量化后不稳定也会导致编译失败；通过检查不等于已验证听感或硬件内部余量。

输出衰减不改变手机音量键步进，也不是动态压限器。Android App 的参数标签不完整表达本工具写入的系数，重新保存可能覆盖其效果。具体生效情况以读回为准。
