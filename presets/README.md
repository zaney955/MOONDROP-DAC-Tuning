# JSON 格式

每个 JSON 是一份完整听音设置，写入时整体替换设备 EQ。名称、用途和具体数值只维护在文件内；用 `python3 tools/preset.py list` 查看列表。操作步骤见[操作指南](../docs/operations.md)。

| 字段 | 含义与范围 |
| --- | --- |
| `version` | `1` |
| `device` | `MOONDROP ECHO-B`，指耳放而非耳机 |
| `name` / `description` | 显示名称与用途；名称不能为空 |
| `output_gain_db` | 必填的整体输出数字增益，约 −132.453198 至 +6.020599 dB，可用小数；`0` 表示单位增益 |
| `filters` | 最多 8 段，空数组表示不改变频响形状 |

第 9 段实现 `output_gain_db`，前 8 段负责音色滤波。范围由单个有符号 24 位 Q22 正系数决定：最小 `1 / 2^22`，最大 `(2^23−1) / 2^22`，对应 dB 边界的精确值由编译器计算；例如 `+6.02` 有效，`+6.03` 超出范围。接近负向极限时量化步进很粗，不能理解为任意小数都能精确生效。零系数静音不属于有限 dB 参数。

这两个系数端点已在本机 ECHO-B 临时写入并读回验证，不能等同于模拟输出的增益、噪声或失真测量，详见[增益范围记录](../docs/devices/echo-b-output-gain-range.md)。它不是模拟增益或 EQ 前级控制，也不提高耳放的最大输出能力。组合频响超过 0 dB 时，编译器会提示满幅输入可能削波，不会自动修改请求的增益；前面各级的内部余量仍未验证。未知字段、缺失 `output_gain_db` 或非法数值会停止编译。

顶层 `output_gain_db` 控制整体电平；每个滤波器中的 `gain_db` 只控制该段增益。每个滤波器包含以下字段：

| 字段 | 范围 |
| --- | --- |
| `type` | `peak`、`low_shelf`、`high_shelf` |
| `frequency_hz` | 20–20000 的整数 Hz |
| `gain_db` | −12 至 +12 的整数 dB |
| `q` | 峰值为 0.1–10，量化到 1/256；架式必须为 `1`，对应斜率 S=1 |

单段 `gain_db` 的 ±12 dB 是当前工具的输入限制，不是已测出的统一硬件极限。[滤波器系数写入范围调查](../docs/devices/echo-b-filter-gain-range.md)已验证部分超过 ±12 dB 的系数可写入并准确读回；可表示范围随类型、频率、Q 值和采样率变化。本轮没有扩大日常预设接口的范围，也没有模拟频响回录。

同参数不保证与安卓官方 App 得到相同曲线：当前工具的峰值 Q 定义、架式 S=1 和固定 Q22，与被调查官方版本的计算方式不同，详见[官方系数对比](../docs/devices/echo-b-android-eq-comparison.md)。移除输入范围限制本身不会解决这些差异。

限制以[编译器](../tools/preset.py)为准。系数溢出或量化后不稳定也会导致编译失败；通过检查不等于已验证听感或硬件内部余量。

输出衰减不改变手机音量键步进，也不是动态压限器。Android App 的参数标签不完整表达本工具写入的系数，重新保存可能覆盖其效果。具体生效情况以读回为准。
