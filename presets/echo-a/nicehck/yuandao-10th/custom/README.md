[死亡金属：Riff 与冲击 v1](yuandao-10th-riff-impact-v1.json)｜2026-11-01

面向资料库记录的 **3.5 mm 原道十周年、全包海绵、ECHO-A**。用户优先听懂吉他 riff 的音高起伏、节奏变化与复杂编曲的逻辑，同时保留适度低频冲击；本配置是这一偏好的试听起点，改善程度尚未经过用户试听。

## 参数与设计意图

五段均为 RBJ 峰值滤波器，Q 是带宽参数。表中为源 JSON 参数，各段增益会互相叠加，不能直接当成最终曲线。

| 频率 | 增益 | Q | 设计意图 |
| --- | --- | --- | --- |
| 90 Hz | +3.0 dB | 0.8 | 用宽峰值补鼓与贝斯的冲击、支撑，限制向极低频延伸的提升 |
| 250 Hz | −1.8 dB | 0.9 | 轻收中低频厚重感，尝试降低密集段落的堆积，同时保留低音吉他主体 |
| 850 Hz | +0.8 dB | 0.8 | 温和保留吉他中频存在感，避免只剩低频与拨弦边缘 |
| 1600 Hz | −1.2 dB | 1.1 | 结合官方无海绵图的宽隆起，轻微约束这一带，避免相邻提升叠得过突出 |
| 3000 Hz | +2.0 dB | 0.9 | 温和突出吉他轮廓与起音，帮助跟随快速 riff 的节奏变化 |

这是听音意图与调音假设，并非乐器频段的独占分配。EQ 同样会影响这些频段里的军鼓、人声和镲片，无法分离录音中已经重叠的乐器。

实际量化后总响应约为：60 Hz **+1.94 dB**、90 Hz **+2.70 dB**、250 Hz **−1.06 dB**、850 Hz **+0.49 dB**、1600 Hz **−0.06 dB**、3000 Hz **+1.72 dB**、6000 Hz **+0.64 dB**。1600 Hz 单段虽为负值，叠加相邻段后接近 0 dB；这里的作用是控制累积提升。20 Hz 仅约 +0.23 dB，未尝试把明显滚降的深低频补平。6 kHz 以上没有独立提升段，但宽峰值的尾部仍有影响。

## 依据与适用边界

[耳机资料库](../../../../../headphones/nicehck/yuandao-10th/README.md)及其中保存的 [NICEHCK 官方频响原图](https://cdn.shopify.com/s/files/1/0865/0850/3331/files/06_15b37029-c621-4a3d-bb60-f66028fc9bbb.jpg?v=1773218463)显示无海绵条件下的低频滚降和约 1.6 kHz 宽隆起。图注明 3.5 mm 无麦、无海绵、B&K 5128；不能据此精确推算全包海绵或个人耳内响应。因此没有按图片反向拟合，也没有复制网友预设或 Type-C 官方预设的较大增益。

实现使用当前 [ECHO-A 编译器](../../../../../tools/echo_a.py)：固定 93,750 Hz、Q 与增益先量化到 1/256，再设计有符号 Q30 系数；使用 [RBJ Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/) 峰值公式。不改算法，未用三段由编译器填充为中性段。

## 电平与试听

按[当前配置约定](../../../../README.md#整体增益约定)，JSON **省略 `output_gain_db`**，缺省编译值是 **0 dB**，不是保持设备原电平。该配置 EQ 最高约 **+2.71 dB**，因此建议在编辑器中先手动把数字前级设为 **−4 dB**：模型中输出峰值约 −1.29 dB；这不是对所有信号、内部处理或模拟输出无削波的保证。不要以提高播放音量追求身体震感。

导入编辑器后，固定海绵、摆位、同一段录音，匹配听感音量比较。优先听：快速 riff 能否一路跟住、双踩是否盖住吉他、贝斯是否可跟随、持续听是否刺耳。建议每次只改一段：

- 鼓仍盖住 riff：将 90 Hz 从 +3 改为 +2 dB。
- 吉他变薄、贝斯失去主体：将 250 Hz 从 −1.8 改为 −1 dB。
- 吉他、军鼓或人声太冲：将 3000 Hz 从 +2 改为 +1 dB。

这些微调仍需重新预览总响应。平头耳机的佩戴与录音差异会影响结果，EQ 不能保证获得身体触觉式的低频。

## 离线验证

CLI `build`、网页 `preview`、Q30 数值范围与量化后稳定性均通过；20–20000 Hz 的 12,001 点扫描范围约为 **−1.10 至 +2.71 dB**。详见[验证记录](../../../../../headphones/nicehck/yuandao-10th/analysis/echo-a-riff-impact-v1-validation.json)，其中保留配置及实现 SHA-256、量化参数、系数、极点和频率采样值。

复核命令（在仓库根目录执行）：

```sh
python3 tools/dac.py build presets/echo-a/nicehck/yuandao-10th/custom/yuandao-10th-riff-impact-v1.json
```
