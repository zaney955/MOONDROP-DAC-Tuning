# ECHO-B 参数与算法

用户输入字段见 [JSON 格式](../../presets/README.md)，本页解释实现范围、量化与官方 App 差异。以下范围属于本工具，不概括全部硬件能力。

## 频率与滤波增益

频率输入限制为 20–20000 的整数 Hz，前后端及频响预览使用同一范围。频率指峰值中心或架式增益中点，不表示影响只发生在这个频点。

`gain_db` 接受 0.1 dB 步进的有限数值，没有固定上下限。实际可编译范围取决于类型、频率、Q 和采样率。五种采样率都必须通过有限数值、有符号 24 位 Q22 编码与量化稳定性检查；单采样率合法不等于完整预设可用。

范围外的离线算例可以产生合法系数，但没有据此扩展正式接口。维持五采样率模型时，统一频率上端还须低于最低采样率的 Nyquist 频率 22050 Hz；符合这一条件也不保证量化稳定或准确。离散通过样本不是连续可用区间。原生字段能表达 0–65535 也不等于算法或固件全范围支持。

[频率扩展检查脚本与结果](../../evidence/filter-frequency-range-20261030/results.json)保留了输入、返回码和源文件哈希。官方函数模拟中的数学异常属于模拟器限制，不应解释为 Android 或固件行为。

## 整体输出数字增益

第 9 段使用 `[B0, 0, 0, 0, 0]`、Gain=3，线性增益为 `B0 / 2^22`。非零正系数 `1…8388607` 对应：

```text
最小：20 × log10(1 / 4194304)       = −132.45319809215172 dB
最大：20 × log10(8388607 / 4194304) =   +6.020598877840829 dB
```

输入可用小数，实际按 Q22 舍入。接近下限时量化步进很粗；零系数表示静音，不用有限 dB 表达。此范围仅适用于固定缩放的单系数实现。

整体输出位于第 9 段，不是模拟增益或 EQ 前级。组合频响超过 0 dB 时可能削波；最终输出留有余量也不能证明前面各级没有内部溢出。编译成功不保证标称增益精度、模拟输出精度或无失真。

## 与官方 Android App 的差异

同样的类型、频率、Q 和增益，不保证产生相同系数或频响。

| 项目 | 本工具 | 已分析的官方计算库 |
| --- | --- | --- |
| 峰值 Q | `sin(w)/(2Q)` | Q 转 octave bandwidth，再使用含 `w/sin(w)` 的带宽公式 |
| 架式 | 固定 S=1 | Q 型架式，Q=1 不等于 S=1 |
| Q 量化 | 四舍五入到 1/256 | 向零截断到 1/256 |
| 浮点计算 | Python double | float32 |
| 缩放 | 固定 Gain=3 / Q22 | 动态 Gain，24 位还原尺度为 `2^(25−Gain)` |

例如 48 kHz、peak、10 kHz、Q=1、+6 dB 的计算频响最大差约 0.96 dB；20 kHz 同条件约 5.04 dB。它们是数字模型比较，不是模拟输出测量。比较原始整数系数前必须考虑缩放；当前解析器拒绝 Gain≠3，不说明设备不支持其他缩放。

单段小数增益参与完整系数计算，设备整数标签向零截断：如 +1.9 → +1、−1.9 → −1、±0.1 → 0。历史计划没有独立 `gain_label_db` 时，复核继续使用其原整数标签，不重新计算系数。官方 App 重新保存可能覆盖本工具设置，不能仅凭标签判定实际 EQ。

依据为 APK `2.25.0c-260813ai`（versionCode `102034`），SHA-256 `04756b49acfea523758d86101c96c1824b7b209ae3a8836c07837088e795d2d5`。官方函数通过 ARM64 模拟执行，libm 桥接主机数学函数；这不是 Android UI 抓包或物理 Android 全部末位行为的证明。

## 诊断工具

`echo_gain_probe` 和 `echo_filter_probe` 属于临时修改探测器，要求模式 0、第 8 段直通、第 9 段为非正纯增益，并在 `preset.device_lock()` 下调用。工具保存并刷盘原始回包后，将第 8 段静音再测试；恢复时先核对第 9 段，再恢复第 8 段。它们不发送闪存保存或固件命令。

SIGINT／SIGTERM 会请求恢复；第 9 段恢复无法核实时第 8 段保持静音。掉电、拔线或强制终止不能保证自动恢复。仅从对应设备的原始备份恢复，不能使用他人的测试文件：

```python
import sys
import subprocess
sys.path.insert(0, 'tools')
import preset

backup = 'runs/实际运行目录/original-bands-8-9.bin'
with preset.device_lock():
    subprocess.run(['bin/echo_gain_probe', 'restore', backup], check=True)
```

日常调节使用 `dac.py` 或编辑器；探测器不能代替预设写入和回退流程。
