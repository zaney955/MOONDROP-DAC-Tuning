# 设备参考

当前设备控制后端仅支持 macOS。网页和统一 CLI 共用编辑器及记录格式，按 `device` 字段选择独立适配器；不支持的设备、参数或报告会停止操作。

## 编辑能力

| 项目 | ECHO-A | ECHO-B |
| --- | --- | --- |
| USB | `3302:12c5`，产品名 ECHO-A，本地固件 0.1 | `35d8:149b` |
| EQ 段数／频率 | 8 段／20–20000 整数 Hz | 同左 |
| 类型 | 峰值、S=1 低架 | 峰值、S=1 低架和高架 |
| 单段增益 | ±10 dB，按 1/256 dB 量化 | 0.1 dB 步进，范围由系数校验决定 |
| 峰值 Q | 0.1–10，按 1/256 量化 | 同左 |
| 整体电平 | 整数前级 −30 至 0 dB | 第 9 段末级输出，约 −132.453198 至 +6.020599 dB |
| 系数 | 有符号 Q30，固定 93,750 Hz 设计率 | Q22，44.1 / 48 / 96 / 192 / 384 kHz |
| 提交与验收 | 提交序列无独立保存 ACK；核对 8 段元数据、160 字节系数和前级，再独立读取 | 核对 56 条 ACK、模式、元数据和当前运行系数 |

这是当前软件接口范围，不是硬件全部极限。ECHO-A 的第三方公开证据还包含低通、高通和模拟高架，但本编辑器未开放这些类型。两型号的 `output_gain_db` 均可省略，规则见[预设格式](../../presets/README.md#整体增益约定)。
