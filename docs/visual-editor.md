# 编辑器指南

```sh
python3 tools/editor.py --open
```

也可运行 `make editor`。默认地址为 [127.0.0.1:8765](http://127.0.0.1:8765)；端口占用时加 `--port 8766`。环境要求见[首页](../README.md)。

## 选择与读取

先选择设备型号，或点击“识别已连接设备”，再选择该型号的预设、新建草稿或“读取当前设备”。识别只查 macOS USB 注册表，读取才查询 HID；打开页面和状态轮询不自动读写设备。

读取保存两轮一致的参数和系数，仅在能精确复现时载入草稿。ECHO-B 从 Q22 系数恢复小数增益；ECHO-A 核对 Q8.8 参数与 Q30 系数。设备不保存原配置名称和备注。不支持的模式、类型或系数会保留原始记录并说明原因，读取失败保留原草稿。

切换型号、预设、导入、新建或读取若会丢弃未导出修改，页面会提示确认。型号之间不自动转换系数；能力限制见[设备参考](devices/README.md#编辑能力)。

## 编辑与历史

选中曲线编号点后，下方显示该段参数。滤波器按频率排序，同频率保留原顺序，选中状态跟随滤波器。

| 操作 | 方法 |
| --- | --- |
| 频率／增益 | 拖动编号点，或使用输入框、滑块 |
| 新增／删除 | 点击新增或双击图中空白处；选中后删除，最多 8 段 |
| 峰值 Q | 输入数值或在编号点上滚轮调节；向上增大 |
| 重置增益 | 重置此段／全部 EQ；保留频率、类型、Q 和整体电平 |
| 撤销／重做 | 图上方按钮；只恢复草稿，不回滚设备 |
| 适应范围 | 自动缩放纵轴，或点击“适应范围” |

拖动、增益滑块和上下键按 0.1 dB 调节；ECHO-A 输入框还可保留精确的 Q8.8 读回值。无效或未完成的输入保留上次有效预览，修正并通过校验后才能导出或写入。

| 快捷键 | 操作 |
| --- | --- |
| ⌘Z / Ctrl+Z | 撤销 |
| ⇧⌘Z / Ctrl+Shift+Z；Ctrl+Y | 重做 |
| 控制点左右／上下键 | 频率 ±1 Hz／增益 ±0.1 dB；Shift 改为 100 Hz／1 dB |
| Shift＋滚轮 | 峰值 Q 步进 0.01，普通滚轮步进 0.1 |
| Esc | 取消拖动或收起读数 |

历史最多 100 个状态；一次拖动计一步，连续输入合并。载入、导入或新建重新开始历史；输入法组字不拦截快捷键。

## 曲线与读数

实线是 EQ 组合，虚线是单段响应，编号点表示该段自身的频率和增益；架式点通过细线连接其单段曲线。**图形不包含整体增益或耳机声学响应**，校验提示中的“输出峰值”才包含整体增益。

预览由量化系数计算。ECHO-B 可切换五种采样率；ECHO-A 的 93.75 kHz 是固定 DSP 设计率，不是当前 USB 音频流采样率。纵轴包含 0 dB 并保留留白，最小跨度 6 dB；拖动期间固定，松手后适配。

鼠标靠近曲线会显示吸附读数，按住横移可跟随同一曲线；触屏横滑查看、纵滑滚动，不改变参数。Tab 聚焦图表后可用左右键查看、Shift 加速、Home／End 到两端。读数按对数频率插值，非法参数时隐藏。

## 整体增益与文件

新建草稿的整体增益留空，默认按 0 dB 处理，导出时省略字段；手动输入或操作滑块才显式设置，手动填写 0 会保留 0。读取设备保留真实电平。完整规则见[预设格式](../presets/README.md#整体增益约定)。

导入接受不超过 64 KiB 的 JSON，先校验再替换草稿；导出不自动改写仓库文件。将保存的 JSON 放入对应 `presets/` 分类目录可加入预设库。关闭页面前导出需要保留的修改；自动重载恢复本标签页草稿和历史，但不代替文件保存。

## 写入与复核

确认目标型号、降低播放音量、关闭其他控制程序后，点击“写入耳放”。保持连接并等待结果；操作卡片显示阶段、提交／ACK、读回结果和 `runs/` 路径。两型号的保存证据不同，具体含义见[操作状态](operations.md#写入)。网络中断后页面只查询任务状态，不重发写入。

“只读复核上次写入”比较已保存计划，不应用当前草稿；读取当前设备也不会改变该复核目标。关闭网页不会取消已开始的设备操作。使用完毕等操作完成后，在服务终端按 Ctrl+C。固件升级、复位、模拟增益和麦克风写入不属于本编辑器功能。
