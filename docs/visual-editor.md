# 编辑器指南

在仓库根目录运行：

```sh
python3 tools/editor.py --open
```

也可使用 `make editor`。默认地址为 <http://127.0.0.1:8765>；端口占用时，用 `python3 tools/editor.py --port 8766 --open` 更换端口。环境要求见[首页](../README.md)。

## 编辑配置

从左侧选择预设，或新建空白配置。默认草稿使用空白 EQ 和 −16 dB 整体输出；它不表示设备当前状态。选中曲线上的编号点后，下方显示该段参数。

| 操作 | 方法 |
| --- | --- |
| 调整频率、增益 | 拖动编号点，或使用输入框和滑块 |
| 新增滤波器 | 点击新增，或双击绘图区空白位置；最多 8 段 |
| 删除滤波器 | 选中后点击删除 |
| 调整峰值 Q | 输入数值，或在编号点上滚轮调节；向上增大、向下减小 |
| 重置增益 | “重置此段”或“重置全部 EQ”；保留频率、类型、Q 和整体输出 |
| 撤销／重做 | 使用图上方按钮；只修改草稿，不回滚设备操作 |
| 显示完整曲线 | 纵轴随当前值自动适配，也可点击“适应范围”重新计算 |

滤波器支持峰值、低架和高架；频率为 20–20000 的整数 Hz，增益按 0.1 dB 调节。峰值 Q 为 0.1–10，架式固定斜率 S=1。增益输入框没有固定上下限，实际组合由编译器校验。新增或提交频率修改后，滤波器按频率从低到高编号，选中状态跟随原滤波器。

编号点表示该段自身的频率和增益。实线表示叠加整体输出增益后的总响应，虚线表示单段响应；架式编号点与其转折处曲线之间会显示连接线。预览由实际量化系数计算，可切换 44.1 / 48 / 96 / 192 / 384 kHz。它不包含耳机声学响应，也不读取设备。

纵轴根据当前采样率的总响应、单段响应和控制点增益自动扩展或收缩，始终包含 0 dB 参考线，并保留上下留白；最小显示跨度为 6 dB。拖动控制点期间固定范围，松手且预览校验通过后更新，避免缩放改变拖动手感。调整输出、重置、撤销／重做及切换采样率后也会自动适配。无效或尚在计算的参数保留上次有效范围。

无效或未填完的参数会保留，页面显示原因并标记上次有效预览。任一采样率不通过时，不能导出或写入；详细规则见 [JSON 格式](../presets/README.md)。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | Mac：⌘Z；Windows／Linux：Ctrl+Z |
| 重做 | Mac：⇧⌘Z；Windows／Linux：Ctrl+Y 或 Ctrl+Shift+Z |
| 聚焦控制点 | Tab |
| 移动控制点 | 左右每次 1 Hz，上下每次 0.1 dB；Shift 分别改为 100 Hz、1 dB |
| 取消当前拖动 | Esc |
| 微调峰值 Q | Shift＋滚轮，步进 0.01；普通滚轮步进 0.1 |

撤销历史最多 100 个状态，一次拖动计为一步，连续输入会合并。载入预设、导入或新建会重新开始历史；输入法组字期间不拦截快捷键。

## 保存与导入导出

“导出 JSON”下载名称、备注、滤波器和整体输出增益。编辑器不自动改写仓库文件；将导出的 JSON 放入 `presets/`，可将其加入预设库。“导入配置”接受本仓库 JSON 格式，最大 64 KiB；校验失败保留原草稿。

有未导出的修改时，切换预设、新建或导入会提示确认。关闭标签页前请导出需要保留的配置。代码自动重载会暂存并恢复本标签页草稿和撤销历史，但不代替文件保存；开发机制见[开发指南](development.md#自动重载)。

## 写入与复核

只有点击“写入耳放”才会开始写入。操作前降低播放音量，确保只连接一台 ECHO-B，并关闭其他控制程序。写入会整体替换音色和输出数字增益，操作期间保持连接并等待结果。

页面区分“已验证”“已保存但未验证”和“写入结果未知”。读取暂时失败时会有限重连，只重新查询，不重发写入。网络中断后页面也只查询操作状态。

“只读复核上次写入”对比本次服务保存的操作计划，不会应用后来编辑的草稿。退出服务后，可用命令行 `python3 tools/preset.py verify runs/实际目录` 复核。状态含义、回退和排障见[操作指南](operations.md)。成功读回不等于已验证物理拔插保持。

服务仅监听 `127.0.0.1`。使用完毕在终端按 Ctrl+C；设备操作已开始时应先等待完成。关闭网页不会取消已启动的写入。
