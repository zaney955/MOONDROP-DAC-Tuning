# 可视化调节工具

在仓库根目录运行：

```sh
make editor
```

会启动本地服务并打开默认浏览器。也可以运行 `python3 tools/editor.py --port 8765`，自行打开 <http://127.0.0.1:8765>；端口占用时换一个 `--port`。需要 Python 3.9 或更新版本，网页没有第三方运行依赖。设备通信沿用本仓库 macOS 后端，首次写入需要 Xcode Command Line Tools 提供的 `make` 和 `clang`。

## 代码自动重载

默认启用。修改 `tools/` 内的 Python／C 代码、`web/` 网页资源、`presets/` JSON 或 `Makefile` 后，服务等待保存稳定约 0.6 秒，检查新代码，再自动重载。`runs/`、备份、编译结果和 Python 缓存不在监听范围内，不会因设备日志更新而反复重启。可用 `python3 tools/editor.py --no-reload` 关闭监听。

每次服务启动都固定一份代码版本和网页资源快照，页面请求也携带版本。服务切换后，旧版页面的写入请求会在访问设备前被拒绝，页面通过只读版本检查自动跟随更新。设备写入／只读复核尚未完成时，重载会延迟到操作结束；不会中断、自动重发或恢复执行设备操作。

页面自动刷新前，会把当前草稿暂存在**本标签页的 sessionStorage**，包括未通过校验／尚未填完的输入、未导出状态、预览采样率和滚动位置，更新后恢复。不会为自动刷新弹出丢弃修改提示；存储不可用时保留当前页面并提示先导出。持续输入或拖动期间也会推迟页面刷新。这只服务于代码重载，关闭标签页前仍应导出需要保留的配置。

Python 语法及导入错误会保留原版本继续运行，页面显示检查错误；修正代码后会再尝试重载。若本机有 Node，也会在切换前检查 `web/app.js` 的语法。自动重载保留页面会话令牌、上次运行目录及其成功／失败状态，已保存但未验证的状态不会因重启被改成成功。

从不支持自动重载的旧版页面升级时，需先导出重要草稿并手动刷新一次；之后的代码修改会自动跟随更新。

## 调节与预览

- 以 EQ 图为主体，图与调节区位于同一个面板。载入配置时不展开滤波器列表；点击图上的编号点，只显示对应一段的类型、频率、增益和 Q。拖动、方向键或滚轮操作也会选中该点，选中曲线与编号会高亮。选中的控制点旁会显示类型、频率、增益与 Q，并随拖动／滚轮实时更新；低架／高架显示固定斜率 S=1。信息框靠近边缘时自动换边并保持在绘图区内，不阻挡鼠标或触摸操作。
- 在图下方的调节区新增或删除滤波器。新增后直接选中新段，并尽量选择远离现有点的初始频率；删除后回到未选择状态。整体输出数字增益常驻同一调节区，配置名称与备注放在其后，写入按钮位于最后。尚未填完的参数会保留，切换到别的点后仍可回来补全；自动重载也会恢复选中的滤波器。
- “重置此段”将所选段增益归零；“重置全部 EQ”将所有段增益归零，保留频率、类型、Q、整体输出以及配置名称和备注。重置后可点击“撤销重置”恢复上一次增益；继续修改参数或载入配置后撤销入口消失。重置会重新校验和预览，只修改草稿，不访问设备。
- 双击 EQ 图绘图区的空白位置可新增峰值滤波器，Q 初始为 1，频率按横向对数坐标取整到 Hz，增益按 0.1 dB 取值，并自动选中新点。纵坐标直接作为新增滤波器的自身增益，不扣除已有 EQ 或整体输出增益，让新点对应点击高度。双击已有点、坐标轴或绘图区外不会新增；最多仍为 8 段，设备操作期间及参数尚未校验通过时不新增。
- 无论工具栏新增还是双击新增，都会按频率从低到高重排滤波器和编号，导出的 JSON 也使用该顺序。拖动松开、频率输入提交或方向键改频率后同样重排；同频点保留原有相对顺序。选中状态跟随同一个滤波器，重编号不会把增益、Q 或焦点错移到其他段；Esc 取消拖动时恢复原参数与顺序。
- 左侧从仓库 `presets/` 读取预设。默认打开 −16 dB 原始音色配置；这只是编辑起点，不表示设备当前状态。新建配置也是空白 EQ、−16 dB 整体输出。
- 最多 8 段滤波器。每段频率支持 **20–20000 Hz 之间任意整数 Hz**，不限固定频点。可直接输入 137、2836 等数值，也可用对数频率滑块。滑块方向键每次调整 1 Hz，Shift＋方向键调整 100 Hz。
- 提供峰值、低架、高架三种类型，支持增益与 Q 调节。单段增益的数字框、滑块及曲线拖动统一使用 0.1 dB 步进。增益数字框不设固定上下限；滑块默认覆盖 −24 至 +24 dB，输入超出此区间的值时会扩展滑块。实际是否有效仍由编译器决定。
- 整体输出数字增益支持完整 Q22 正系数范围及小数；频率图包含此增益。架式固定 S=1，峰值按 1/256 量化 Q，并显示实际 Q。
- 频响图根据现有编译器输出的 **实际 Q22 系数**计算，支持五种采样率切换；实线为组合响应，虚线为每段 EQ。移动指针可查看频率与组合增益。它是数字模型，不是耳机实测曲线，也不代表设备实时读回。
- 可直接用鼠标或触屏拖动曲线上的编号控制点：左右调整频率，上下调整该段增益，输入框和滑块同步变化。频率按对数坐标移动并取整到 Hz，增益按 0.1 dB 量化；控制点始终表示该段自身的频率和完整增益，架式也不按中心响应折半；其他段和整体输出增益不会影响其坐标。总频响曲线正常叠加计算，选中的单段虚线加粗并置于最上层。低架／高架控制点与各自在设定频率处的单段虚线之间显示同色细连接线，虚线端以小空心圆标记，选中时加深；连接线随预览更新，不影响任何段的参数或控制点坐标。纵轴在编辑和松开后均保持固定，避免自动缩放让其他控制点跳动；载入配置时自动适配，编辑后可点击“适应范围”重新显示完整曲线和超出视野的控制点。持续更新编译器曲线，松开后完整校验；无效组合保留输入并显示原因。Esc、触摸手势取消或指针捕获丢失会恢复该次拖动前的频率和增益。拖动不会写入设备。
- Tab 可聚焦控制点，左右方向键每次调整 1 Hz，上下方向键每次调整 0.1 dB；按住 Shift 时分别为 100 Hz、1 dB。参数输入框和滑块仍可独立使用。
- 将指针放在峰值滤波器的编号控制点上滚动滚轮，可调整 Q：向上增大 Q（更窄），向下减小 Q（更宽），普通步进 0.1，Shift＋滚轮精调步进 0.01，范围 0.1–10。不同滚轮／触控板的位移会按像素、行、页单位换算并累计，避免细碎事件让参数跳变。输入框、控制点提示和曲线同步更新；实际 Q 仍由编译器按 1/256 量化。仅峰值控制点处理此滚轮操作，其他区域照常滚动，缩放手势照常使用；架式斜率固定 S=1。

每次修改都调用同一个 `preset.compile_preset()` 校验五种采样率。任意整数频率可输入，不代表任意频率、Q、增益组合都能通过 Q22 稳定性与范围检查。非法组合会显示原因，图中保留并标记上次有效预览，不会自动截断参数或导出非法配置。

## 配置导入与导出

“导入配置”接受本仓库[预设 JSON 格式](../presets/README.md)，最大 64 KiB。完整校验通过后才会替换当前草稿；导入失败保留原配置。有未导出的修改时，切换预设、新建或导入会询问是否放弃修改。

“导出 JSON”下载完整配置，包含名称、备注、所有滤波器和 `output_gain_db`，与命令行格式一致。下载文件可再次导入，或用于：

```sh
python3 tools/preset.py build '/路径/导出的配置.json'
python3 tools/preset.py apply '/路径/导出的配置.json'
```

编辑器不自动改写仓库预设。若要收录到左侧预设库，将导出的 JSON 放入 `presets/` 后刷新网页。关闭页面前请导出需要保留的草稿。

## 写入与只读复核

只有明确点击 **“写入耳放”** 才会启动设备操作；载入、调参、导入、导出及预览不访问 USB。输入框的 Enter 不会意外触发写入。

写入复用现有设备锁、写前读取、56 条 ACK、保存和读回验证流程，完整快照及证据保存在 `runs/时间戳-visual-editor/`。操作期间锁定编辑控件，页面显示真实阶段、保存 ACK 和读回结果。失败不会自动重试写入或回滚；“已保存但未验证”和“写入结果未知”按现有工作流分别显示。发生网络中断时只重新查询操作状态，不重发写入。

保存后若读回遭遇 `0x10000003` 通信目标失效，会自动重新枚举并打开设备，只做查询和原计划复核。每段采集最多 3 次（首次加 2 次恢复），与 NotReady 重试共用上限。界面显示重连进度／次数，通过后自动更新为“已验证”；权限错误、非法回包、系数不匹配及恢复耗尽仍会保留失败状态。操作中约每 0.7 秒、空闲时约每 2 秒查询服务端记录，也会同步后台启动的只读复核结果；页面轮询本身不访问 USB。

本次服务产生写入计划后，可点击“只读复核上次写入”。它对比上次操作的历史计划，不会应用后来在界面中编辑的草稿。自动重载会保留此记录；完全退出后重新启动时，历史操作仍可通过命令行 `python3 tools/preset.py verify runs/实际目录` 复核。成功读回不表示已验证物理拔插保持。

服务仅监听 `127.0.0.1`，检查 Host、Origin 和会话令牌；不向局域网开放，也不加载远程字体、脚本或分析服务。使用完毕，在启动它的终端按 Ctrl+C。设备操作已启动时请等待完成并保持连接；关闭网页不会取消设备写入。

## 开发验证

`make test` 运行编译器、HTTP 和模拟设备回归，不访问真实 USB。可选浏览器回归位于 `tools/test_editor_browser.cjs`：先启动编辑器，再在能解析 `playwright` 的 Node 环境中运行 `node tools/test_editor_browser.cjs`（可用 `NODE_PATH` 指向已有依赖目录）。默认使用本机 Chrome，`EDITOR_URL` 可指定其他本地端口。浏览器测试覆盖 0.1 dB 输入与滑块、小数增益导入导出、鼠标／触屏拖动、曲线持续更新、边界、取消恢复、键盘和参数同步，不触发设备写入。

`node tools/test_editor_reload.cjs` 会独立创建临时项目副本，实际修改代码，验证服务和页面同步重载、草稿和无效输入恢复、资源快照、语法错误回退与修复。它不修改当前仓库文件，也不启动设备操作。

`node tools/test_editor_creation.cjs` 对正在运行的编辑器验证图中双击新增、坐标对应、自动选择、从左到右编号、跨点拖动、焦点与导出顺序、误触及八段上限；不启动设备操作。依赖与端口设置方式同其他浏览器回归。

`node tools/test_editor_handles.cjs` 验证峰值／架式控制点直接对应单段完整增益，相邻控制点和参数在拖动、松开、Q、输出增益和采样率更新时保持稳定，总频响实时更新，选中单段曲线高亮及手动适应范围；不启动设备操作。
